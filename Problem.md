# Algorithm for Finding Even and Odd Numbers

1. **Start**
2. **Input:** Read an integer value from the user (let's call it `N`).
3. **Condition Check:** Evaluate the remainder when `N` is divided by 2 (`N % 2`).
   * **If `N % 2 == 0`:**
     * Output: The number `N` is **Even**.
   * **Else:**
     * Output: The number `N` is **Odd**.
4. **End**
